# Social Media Engagement Analytics Using Python

## Project Overview

This project focuses on analysing social media engagement data using Python. It explores user behaviour, post performance, engagement metrics, and sentiment patterns.

## Dataset

**File Name:** `social_media_engagement_5000.csv`

The dataset contains information about:

* User details
* Post types and categories
* Likes, comments, and shares
* Impressions and watch time
* Engagement rate
* Sentiment and hashtags
* Device type and country

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly

## Project Tasks

1. Data Import and Setup
2. Data Cleaning
3. Data Exploration
4. Data Wrangling
5. Statistical Analysis
6. Data Visualization
7. Final Insights

## Key Objectives

* Understand social media engagement patterns.
* Identify high-performing post categories.
* Analyse user behaviour and trends.
* Explore sentiment and engagement relationships.
* Generate meaningful insights from data.

## Conclusion

This project demonstrates the use of Python libraries for data cleaning, analysis, statistical operations, and visualization to understand social media engagement.
